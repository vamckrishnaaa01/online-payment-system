# PayFlow — Online Payment System

A responsive online-payment frontend built from the visual direction of the supplied reference video: dark cinematic interface, oversized typography, restrained motion, thin borders and a focused transaction flow.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage for demo transaction history

## Features
- Responsive landing page
- Payment form with validation
- UPI / Card / Netbanking selectors
- Payment review modal
- Demo confirmation flow
- Transaction history persisted in browser localStorage
- No real payment processing or card data collection

## Run
Open index.html directly in a browser, or use VS Code Live Server.

## Next step
Connect the form to a Java Spring Boot REST API and a payment gateway sandbox. Keep secrets and gateway credentials on the backend.
